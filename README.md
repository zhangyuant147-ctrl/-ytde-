# 张元通 Yuantong. / 个人创作空间

采用近黑、银灰与柔和紫色光线的个人作品网站。首页连续浏览：三维镜头入场与互动人物 → 生活照片墙 → 摊手人物与个人介绍 → 坐姿创作人物 → 可筛选的层叠作品集与预留区 → 生活切片 → 联系入口。独立的关于我、作品精选、创作档案、灵感实验室与联系页仍可访问。

## 本地运行

需要 Node.js 22.13+。首次运行 `npm ci`，然后 `npm run dev`。生产构建：`npm run build`。

构建会检查 TypeScript，将产物写入 `dist/`，并同步到根目录的 `index.html`、`assets/`、`favicon.svg` 和 `.nojekyll`。使用相对资源路径，支持 GitHub Pages 子路径。

仓库保存网站源码和可直接托管的静态文件。[现有在线网站](https://clay-studio-1109.leaflesscompass1.chatgpt.site) 单独发布。

## 以后如何补充内容

主要编辑 `site/src/content.ts`，页面会自动读取数据：

- `profile`：姓名、个人简介、方向和电话。当前号码为 15615543731。
- `projects`：作品资料。每项含 `id`、中文/英文标题、分类、封面样式、作品性质、简介、标签、年份、参与内容、过程、成果和项目链接。
- `portfolioSlots`：作品与创作记录预留区。当前展示「待补充」，没有虚假的可点击链接。
- `focusAreas`：关于页与联系页的关注方向。

目前仅「一个人的数字分身」标记为个人创作；另两项明确标记为概念研究，没有填入客户、业绩或未经提供的经历。个人履历、创作记录、外部社交平台均有留白。

添加真实作品时，在 `projects` 中增加一项并填写内容。作品数量和筛选分类会随数据自动更新。自定义封面：把图片放进 `site/src/assets/`，在 `content.ts` 顶部 import，再设置作品的 `cover` 字段；页面会直接显示你的封面。未填封面时沿用内置概念版式。作品年份或链接未知可保留 `null`，页面不生成空链接。作品详情已预留过程和成果展示。

首页与独立页复用 `AboutIntro`、`WorkIntro`、`WorkCollection`，补充资料时两处同步更新。首页的向下浏览按钮只滚动页面，不切换路由。各段共用同一背景色与固定的环境光，不单独铺设色块；人物底部使用透明遮罩渐隐，避免有色遮罩形成横向接缝。

页面模块、联系方式排版与页面标题位于 `site/src/Portfolio.tsx`。全站样式位于 `site/src/styles.css`；鼠标互动样式位于 `site/src/experience.css`。

## 人物与互动

- 关于页、联系页右侧：摊手介绍姿态 `site/src/assets/portrait-presenting.webp`。
- 作品精选、创作档案、实验室右侧：坐姿创作姿态 `site/src/assets/portrait-working.webp`。
- 两张新图使用现有数字分身作为身份参考，用户截图只作为姿态参考。原始透明 PNG 同目录保留；页面使用压缩后的透明 WebP，两张合计约 305 KB。
- 首页和实验室互动展示：仅保留正面和上下左右五张图。移到人物面部中央时回正，没有居中、点击或按钮悬停触发笑脸的行为。
- 人物用基于时间的缓动、中心缓冲区、方向滞回与归一化透明度融合，减少对角线抖动和切换时的透底；躯干保持固定。
- 已恢复惯性圆环光标、按钮磁力吸附、分层视差、星尘、鼠标涟漪和卡片倾斜。首页的长按沉浸与松开回弹覆盖首屏、人物介绍、坐姿展示、作品区及页脚；固定沉浸按钮可持续开启，ESC 可退出。
- 首页保留连续深色背景；新增的三维悬浮物、细轨迹与景深粒子由 Three.js 渲染。关于页仍有浅色的关注方向区块。
- 星尘与涟漪使用单个固定在视口的 Canvas，随滚动覆盖整个首页，不创建与长页面等高的画布。长按不会接管按钮、链接、表单或作品卡片的点击；滚动、失焦和 pointercancel 会结束临时长按。
- 实验室可切换色调与动态效果；系统减少动态效果时自动停用动态。离开首页或页面进入后台时停止绘制。

形象生成工具、输入和提示词见 `ARTWORK.md`。未复制参考站的源码、场景或角色素材。

## 检查

- `node scripts/check-portrait.mjs`：四向映射、中央回正、方向边界稳定性、坐标边界。
- `npm run build`：TypeScript 与生产构建。
- 浏览器检查：桌面六页布局、右侧人物、作品筛选与详情、联系与复制、手机尺寸排版、人物方向和中央回正。


## 生活切片（2026-11-11）

新增驾驶、台球、喝茶、偶尔小酌四个兴趣故事。首页连续浏览中加入生活章节，导航提供独立的「生活切片」页面，关于页加入四张生活缩略图与介绍。首屏增加直达生活章节的入口。照片支持点击放大、关闭按钮、ESC 和遮罩关闭。

兴趣文案和图片入口集中在 `site/src/lifestyle.ts`；布局与样式分别在 `site/src/LifeSection.tsx` 和 `site/src/lifestyle.css`。四张照片为内置 image_gen 生成的写实意境配图，页面保留简短生成标注，不代表用户实拍或拥有所示车辆。完整提示词和素材说明见 `LIFESTYLE-ARTWORK.md`。

WebP 提供 768px 与 1536px 两套尺寸，并使用响应式图片与懒加载。原始 PNG 与修改前备份位于本地工作区 `work/lifestyle-update/`。

## 三维创作空间改版（2026-11-11）

视觉和镜头节奏参考用户提供的 3D Creator 与 Mossline 两份文字，保留张元通自己的资料、四向数字分身、作品与生活照片，没有引用参考中的人物、项目案例、岛屿视频或外部图片。

- 清理各页的英文装饰标签、人物图注和小标语；功能入口使用中文，名字标识保留。
- Kanit 超大银灰姓名标题、近黑背景、金属悬浮几何体与柔和紫色光线。
- 约 2.8 秒的自动镜头推进、分层人物与文字显现，支持跳过和重播；页面内返回首页时直接进入稳定画面。
- 继续滚动时镜头推进、标题散开并显现中文转场；不拦截滚轮与触屏滚动。
- Three.js 景深粒子、金属结与晶体、鼠标视差和点击粒子；原有长按沉浸保留。
- 生活照片墙随滚动横移，照片可以打开；作品卡片 sticky 层叠、缩放、景深和鼠标倾斜；中文介绍按滚动渐亮。
- 动态开关、系统减少动态效果、WebGL 不可用时的静态回退；场景离屏或页面后台时停止绘制，卸载时释放资源。三维模块单独按需加载，手机减少粒子数并限制像素比。

核心文件：`HeroStage.tsx` 管理入场与滚动阶段，`create-studio-scene.ts` 渲染三维场景，`ScrollExperience.tsx` 管理内容显现与作品层叠，`PersonalRibbon.tsx` 展示生活照片墙，`studio.css` 统一新版视觉。文件均位于 `site/src/`。修改前快照和预览截图在工作区 `work/experience-redesign/`。

验证包含 TypeScript/生产构建、原有四向人物检查，以及桌面与手机各页、作品筛选后滚动、详情弹窗、三维开关恢复、开场重播与跳过。
